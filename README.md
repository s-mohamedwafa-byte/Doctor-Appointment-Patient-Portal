# Doctor Appointment & Patient Portal

## Project Overview
The Doctor Appointment & Patient Portal is a software engineering project designed to help patients find doctors, book appointments, and manage their appointment information. Doctors can manage their availability and appointments, while administrators can manage user accounts.

## Main Features
- User registration and login
- Doctor search
- Appointment booking and management
- Doctor availability management
- Prescription management
- User account administration
